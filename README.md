# দৌড়ের উপর রাজনীতি (Dourer Upor Rajniti)

বাংলাদেশের সমসাময়িক জীবিত রাজনৈতিক ব্যক্তিত্বদের নিয়ে একটি ব্যঙ্গাত্মক এন্ডলেস রানার গেম।

## 🎮 গেম সম্পর্কে
খেলোয়াড় একটি চরিত্র নিয়ন্ত্রণ করে "রাজনীতির রাস্তা" ধরে দৌড়ায়, বাধা এড়ায় এবং স্কোর সংগ্রহ করে।

**গুরুত্বপূর্ণ:** এই গেমটি কোনো রাজনৈতিক দল বা ব্যক্তির পক্ষে বা বিপক্ষে অবস্থান নেয় না। এটি শুধুমাত্র বিনোদনের উদ্দেশ্যে তৈরি।
